# meowtropolis-legal

The public web pages for **Meowtropolis**, a mobile game by Ben Dabas.

Right now that is one page: the privacy policy, served at
<https://bendabas.github.io/meowtropolis-legal/>. Google Play requires a
publicly reachable privacy policy URL before a game can be released, and this
repository exists so that URL can be public without the game's own source
being public.

`FINDINGS.md` is the evidence the policy was written from — every claim in the
policy traces to a file in the game's code. **If the game changes what it
collects, change FINDINGS.md first and the policy second**, and update the
effective date at the top of `index.html`.

Nothing secret belongs in this repository. No keys, no server code, no
credentials — everything here is world-readable by design.
